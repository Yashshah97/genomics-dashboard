# Usage

```python
import genomics_dashboard
```

Each module is self-contained; see docstrings for the API:

- `genomics_dashboard.dashboard` — Main application logic and curses setup
- `genomics_dashboard.panels` — Collection of panel classes for displaying data
- `genomics_dashboard.sparklines` — Implementation of sparkline display functionality
- `genomics_dashboard.data_analysis` — Functions for processing DNA/RNA sequence data
- `genomics_dashboard.ui_helpers` — Utility functions for curses UI manipulation
- `genomics_dashboard.tests_test_core` — Unit tests for core application logic
